Zadanie 29 - właściwości, metody i konstruktory

  1. W jaki sposób można ustawić właściwość obiektu?

    Notacją kropkową, np. auto.marka = "Opel";, albo nawiasową, np. auto["marka"] = "Opel";. Notacja nawiasowa pozwala też użyć nazwy właściwości zapisanej w zmiennej.

  2. Jak odwołać się do pól i metod?

    Podajemy obiekt i nazwę jego elementu, np. auto.kolor odczytuje właściwość, a auto.opis() wywołuje metodę.

  3. Jakie są cechy konstruktora?

    Jest używany do inicjalizacji nowego obiektu, może przyjmować argumenty i przypisywać ich wartości do pól. W JavaScript funkcja konstruktora jest wywoływana z operatorem new.

  4. Jak utworzyć obiekt z trzema polami i metodą? 
    const osoba = {
    nazwisko: "Nowak",
    imie: "Anna",
    zawod: "lekarz",
    wyswietl: function () {
        return this.imie + " " + this.nazwisko;
    }
};
  5. Co oznacza this i czym oddziela się elementy obiektu?

    this odnosi się do obiektu, na którym działa metoda. W literałach obiektów właściwości i metody oddziela się przecinkami.

  6. Jak działa konstruktor w JavaScript? 
    function Klient(nazwisko, imie, zawod) {
    this.nazwisko = nazwisko;
    this.imie = imie;
    this.zawod = zawod;
}

    Wartości argumentów są przypisywane do pól nowego obiektu.

  7. Do czego służy słowo kluczowe new? 
    const klient1 = new Klient("Nowak", "Anna", "lekarz");
const klient2 = new Klient("Kowalski", "Jan", "kierowca");

    new tworzy nową instancję i uruchamia konstruktor.

  8. Do czego służy prototype?

    To obiekt, z którego instancje konstruktora mogą współdzielić metody i właściwości.

    Klient.prototype.piszDane = function () {
    return this.imie + " " + this.nazwisko;
};
